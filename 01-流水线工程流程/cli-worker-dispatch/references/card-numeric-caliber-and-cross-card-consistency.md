# 卡面里的"数值与口径"一致性（2026-09-19 实测，卡12c/12e）

顺手记：卡面体量、按行号改写、超长 heredoc 被拦 —— 见 `card-surface-editing-limits.md`；
联动门清单与"只增不减" —— 见 `linkage-gates-and-diagnose-before-dispatch.md`。

## 一、量长度一律用「字符」，**别用字节**（当天最贵的一次误判）

卡面上限口径是**字符**：执行卡 ≤8,000 / 测试卡 ≤6,000 / 合计 ≤14,000。
中文 1 个字符 = UTF-8 **3 字节** → 拿 `len(path.read_bytes())` 去量中文卡面，数字虚高约 3 倍：

| 卡 | 字节口径（误） | 字符口径（真） | 结论 |
|---|---|---|---|
| 任务卡_12c | 10,180 | **6,591** | 合规 |
| 测试卡_12c | 8,285 | **6,007** | 合规 |

我当时按字节判定"超限 8,285"→ 差点把**已经合规**的卡面删内容；改对口径后只需再压 7 个字符。
工人自检输出也用的是字符（`任务卡字符数：4695 / 8000`），两边口径必须一致。

```python
import io
n = len(io.open(path, encoding="utf-8").read())        # ✅ 字符口径
# n = len(path.read_bytes())                            # ❌ 字节口径，中文虚高 3 倍
```

只有**协议层**概念才用字节：请求体上限 65,536 **字节**（`Content-Length` + 分块累计）。

## 二、"密码长度"这类字符 = **Unicode code point**

`len(pw)` 就是 code point 数：英文/数字/中文/emoji 各算 **1**；组合字符（`e`+重音）算 2 —— 只会更严，无害。
不要在规则里写"字节"：按字节算，`爆款心法2026`（8 字）在 UTF-8 下是 16 字节，会被误判成"够长"，
而它的实际强度只相当于 8 个字符。**实现上用 `len()` 即可，无需特殊处理。**

## 三、跨卡共享参数必须**单一来源**（同一数值写在两张卡里 = 定时炸弹）

实测：卡12c（先出、已开跑）把 `scripts/create_admin.py` 的密码护栏定为 **12～1024**；
卡12e（后出）把"新设密码"定为 **8～128**。两张卡各自看都合规，合起来是**三套规则**
（脚本 12～1024 / 注册 8～128 / 登录 仅上限）。

**出卡/初审固定动作**：

1. 先 `grep` 全仓该类常量，确认没有别处已定义同一参数：
   ```bash
   grep -rn "1024\|128\|min_length\|MAX_\|LIMIT" app/ scripts/ tests/ | grep -i "<参数名>"
   ```
2. 参数只允许**一处**权威定义（常量模块 / 服务层 / 裁决冻结契约），卡面写明"取自 <文件>:<符号>"；
3. **后出的卡取代前卡数值时**，在自己卡面里显式写「**同步修改 `<前卡产出文件>`**」并把该文件列入**写入白名单**
   （实例：12e 卡面追加 `scripts/create_admin.py` + `tests/unit/scripts/`，并要求脚本护栏与新策略一致，
   连它的参数化边界测试一起改）；
4. **不要去改前卡的卡面**——前卡可能正在跑（工人开工时已读过它）或已合入；取代关系写在后卡 + 裁决拍板记录里。
5. 用户改判某个数值时（实例：下限 15 → **8**），要一次性落三处：**后卡双卡 + 裁决的"拍板记录"节 + 受影响文件清单**，
   并核对"前卡已写死的数值"是否被覆盖（12c 的 12～1024 就是靠这条被 12e 接管）。

## 四、卡面里的"精确期望值"必须来自**仓库实测**，不是推断

联动门要写精确总数（`IdentityRepositoryPort` 6→10、实现公开方法总 60→64、DTO 字段 185→201、
路由 35→37、202 仍 4、授权矩阵 24 格）。**这些数字在出卡前逐条 grep/读断言核对过**，例如：

```bash
sed -n '/class IdentityRepositoryPort/,/^@runtime_checkable/p' app/domain/ports.py | grep -c "    def "   # → 6
grep -n "assert sum(" tests/unit/repositories/test_repository_contracts.py                                # → == 60
grep -n "assert sum(" tests/unit/test_domain_ports.py                                                     # → == 48
```

写进卡面时**带上来源行号**，初审再核一遍；推断错一个数 = 白烧一整轮。
（实测有效：185+16=201 与工人交付完全一致，正是"先算清再钉"的结果。）
